
# Itinerario + Mapa (versión Live Server)

Puedes abrir el proyecto con la extensión Live Server de VS Code para ver la página cliente sin servidor.

Instrucciones rápidas:

1. Abre la carpeta del proyecto en VS Code.
2. Instala y activa la extensión **Live Server**.
3. Haz clic derecho en `index.html` y selecciona "Open with Live Server".

La página permite ingresar coordenadas en formato `lat,lon` (por ejemplo Bogotá: `4.7016,-74.0721`) y pulsar "Generar mapa" para actualizar la vista.

Si prefieres la versión con servidor (Flask + matplotlib), hay un `app.py` y `requirements.txt` para ejecutar localmente con Python.
